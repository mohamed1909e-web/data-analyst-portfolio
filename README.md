# Data Analyst Portfolio & Client Service Website (Prototype)

Arabic RTL responsive website prototype built with HTML, CSS and JavaScript.

## Included
- Visitor registration (name, email, WhatsApp) stored locally in browser.
- Portfolio sections: Services, Projects, About, Trainings, Certificates, My Orders.
- Service request form and local order tracking.
- Service tiers including custom Pro pricing.
- Responsive styling.

## Run
Open `index.html` in a browser, or host it with GitHub Pages.

## Important prototype limitations
This is a front-end demo. User data and requests are stored in localStorage on the same browser/device only. This is **not** secure authentication and does not provide private client delivery. For real users, implement a backend, authentication, database, file storage and access controls. Avoid collecting sensitive client information in the prototype.

## Customize
Edit arrays near the top of `script.js`:
- `services`
- `projects`
- `trainings`
- `certs`

Replace the placeholder profile block with a portrait and update your real tools/skills. Do not list tools or credentials you haven't actually earned.
